# Енергомоніторинг - веб-інтерфейс

Фронтенд системи моніторингу та аналізу енергоспоживання й параметрів автономного живлення.

## Стек

- React 19 + Vite 6
- d3-scale, d3-shape, d3-array (власні SVG-графіки)
- Власний hash-роутер, Context API, `node:test` для тестів

## Запуск

```bash
npm install
npm run dev      # режим розробки
npm test         # модульні тести
npm run build    # збірка у dist/
npm run preview  # перегляд збірки
```

Потрібен Node.js 20+.

## Сторінки

| Адреса | Призначення |
| --- | --- |
| `#/` | Огляд: показники, графік доби, АКБ, споживачі, сповіщення |
| `#/analytics` | Аналітика за добу, тиждень, місяць; експорт CSV |
| `#/autonomy` | Потік енергії, АКБ, інвертор, калькулятор автономності |
| `#/devices` | Пристрої: пошук, фільтр, сортування, вмикання |
| `#/alerts` | Журнал подій, підтвердження |
| `#/settings` | Тариф, поріг заряду, ємність, тема |

## Структура

```
src/
  api/         імітація серверного API
  components/  UI-компоненти
  context/     автентифікація, налаштування
  hooks/       useAsync, useLiveReading, useSize
  pages/       сторінки
  utils/       розрахунки, валідація, CSV (+ тести)
```

## Безпека

- Валідація всіх полів форм, обмеження довжини
- Захищені маршрути, сесія у `sessionStorage`, автовихід через 15 хв бездіяльності
- Блокування входу на 30 с після 5 невдалих спроб
- React екранує вивід, `dangerouslySetInnerHTML` не використовується
- CSP-заголовок додається під час збірки
- Захист CSV від ін'єкції формул

## Дані

Дані формує `src/api/mockApi.js`. Для підключення реального сервера потрібно замінити його функції на `fetch`-запити.
